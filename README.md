# DST - NPC Additions
Additional NPC mobs using the vanilla Villager Entity model. Mobs are setup to fight one another, and players where it makes sense (hostile mobs). Currently includes the following "Factions", and will attempt to band together if they come within range of each other. 

##Available Factions
###Bandits
###Knight Errant
\
\
Unless otherwise stated, all factions have the same available entities, Spear, Sword, Sword/Shield, and a Line Leader unit (Bandits have Bosses, Knights have Captains).
